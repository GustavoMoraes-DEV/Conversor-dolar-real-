# 💱 Conversor de Moedas

## 📌 Objetivo do Projeto

Projeto desenvolvido em Python com o objetivo de realizar a conversão de valores entre Real (BRL) e Dólar (USD), utilizando uma cotação definida no código.

## 🎯 Funcionalidades

* Conversão de Real para Dólar.
* Utilização de uma taxa de câmbio pré-definida.
* Exibição do resultado formatado.
* Interação com o usuário através do terminal.

## 📚 Conceitos Praticados

* Variáveis.
* Entrada e saída de dados (`input` e `print`).
* Conversão de tipos (`float`).
* Operações matemáticas.
* Formatação de strings com `f-strings`.
* Arredondamento de valores utilizando `round()`.
